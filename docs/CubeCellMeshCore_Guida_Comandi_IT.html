1. Panoramica Hardware e Radio

Hardware

SchedaHeltec CubeCell HTCC-AB01
MCUASR6501 — ARM Cortex-M0+ @ 48 MHz
RadioSemtech SX1262 (integrato nel SiP)
Flash128 KB (97.7% utilizzata)
RAM16 KB (49.7% statica, ~4 KB liberi a runtime)
Deep Sleep~3.5 µA

Parametri Radio Default (EU868)

Frequenza869.618 MHz
Bandwidth62.5 kHz
Spreading FactorSF8
Coding Rate4/8
Potenza TX14 dBm (max)
Sync Word0x12
Connessione Seriale
Collegare via USB e aprire un terminale a 115200 baud. Digitare help per la lista comandi.

2. Primo Avvio e Configurazione Base

Dopo il flash del firmware, il nodo genera automaticamente un'identità Ed25519. Procedere con la configurazione minima:

set name MioRepeater
set lat 45.464161
set lon 9.191383
password MiaPasswordAdmin
set guest.password MiaPasswordGuest
save
Importante
Eseguire sempre save dopo ogni modifica per rendere permanenti le impostazioni in EEPROM.

7. Password e Sicurezza

ComandoDescrizione
passwordMostra password admin e guest
password <pwd>Imposta password admin
set guest.password <pwd>Imposta password guest
get guest.passwordMostra password guest
setperm <pubkey> <perm>Imposta permesso ACL per nodo (0-255, solo seriale)
Sicurezza
Impostare sempre le password prima del deploy. Le sessioni remote scadono dopo 1 ora di inattività. Il rate limiter protegge da attacchi brute-force (5 tentativi login/min).

8. Mailbox Store-and-Forward

Il repeater memorizza i messaggi per i nodi offline e li riconsegna quando il nodo torna online (invia un ADVERT).

ComandoDescrizione
mailboxStato: slot usati/totali, conteggio EEPROM (E) e RAM (R)
mailbox clearSvuota tutti gli slot (solo admin)
Capacità
2 slot persistenti EEPROM + 4 slot volatili RAM = 6 messaggi max, TTL 24 ore. Nessuna configurazione necessaria.

11. Quiet Hours e Circuit Breaker

Quiet Hours

Riduce la frequenza di inoltro durante le ore configurate. Richiede TimeSync.

ComandoDescrizione
quietMostra stato quiet hours
quiet <inizio> <fine>Imposta quiet hours (0-23, es. quiet 22 6)
quiet offDisabilita quiet hours

Circuit Breaker

Blocca l'inoltro DIRECT verso vicini con link degradato (SNR < -10 dB). Dopo 5 minuti passa a half-open. Un buon SNR chiude il breaker. Il FLOOD non viene mai bloccato.

ComandoDescrizione
cbMostra conteggio circuit breaker aperti

17. Profili di Configurazione

Di seguito tre profili preconfigurati per scenari d'uso comuni.

MASSIMA PORTATA

Profilo: Massima Potenza e Copertura

Per installazioni fisse con alimentazione continua (solare, rete). Priorità alla copertura massima e alla reattività della rete.

Comandi di configurazione

mode 0
sleep off
rxboost on
set tx 14
set tx auto off
set repeat on
set flood.max 15
set advert.interval 5
set af 0
set txdelay 50
set rxdelay 50
ratelimit on
alert on
save

Spiegazione parametri

mode 0Performance: nessun risparmio energetico
sleep offDeep sleep disabilitato: sempre in ascolto
rxboost onGuadagno RX potenziato: migliore sensibilità
set tx 14Potenza TX massima (14 dBm)
set tx auto offPotenza fissa, no riduzione adattiva
set flood.max 15Massimo hop per pacchetti flood
set advert.interval 5ADVERT ogni 5 minuti (scoperta rapida)
set af 0Duty cycle disabilitato (TX senza limiti)
txdelay 50Ritardo ridotto: risposte più rapide
RISPARMIO ENERGETICO

Profilo: Minimo Consumo Batteria

Per nodi alimentati a batteria in aree remote. Massimizza la durata con funzionalità essenziali.

Comandi di configurazione

mode 2
sleep on
rxboost off
set tx auto on
set repeat on
set flood.max 3
set advert.interval 30
set af 20
set txdelay 200
set rxdelay 200
set flood.advert.interval 12
quiet 22 6
alert off
save

Spiegazione parametri

mode 2Power Save: massimo risparmio
sleep onDeep sleep attivo: ~3.5 µA tra le finestre RX
rxboost offGuadagno RX standard: minor consumo
set tx auto onTX adattivo: riduce la potenza se non necessaria
set flood.max 3Pochi hop: riduce traffico di rete
set advert.interval 30ADVERT ogni 30 min: meno TX
set af 20Duty cycle 2x: più attesa tra le trasmissioni
txdelay 200Ritardo maggiore: meno collisioni, più sleep
quiet 22 6Inoltro ridotto dalle 22 alle 6
BILANCIATO

Profilo: Uso Bilanciato

Compromesso tra copertura e durata. Ideale per la maggior parte delle installazioni.

Comandi di configurazione

mode 1
sleep on
rxboost on
set tx auto on
set repeat on
set flood.max 7
set advert.interval 10
set af 10
set txdelay 100
set rxdelay 100
ratelimit on
alert on
save

Spiegazione parametri

mode 1Balanced: buon compromesso prestazioni/consumo
sleep onDeep sleep attivo per risparmiare tra le finestre RX
rxboost onGuadagno RX potenziato per migliore ricezione
set tx auto onTX adattivo: potenza variabile in base al link
set flood.max 7Buon raggio multi-hop senza eccesso di traffico
set advert.interval 10ADVERT ogni 10 min: buon compromesso
