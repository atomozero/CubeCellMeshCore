1. Hardware and Radio Overview

Hardware

BoardHeltec CubeCell HTCC-AB01
MCUASR6501 — ARM Cortex-M0+ @ 48 MHz
RadioSemtech SX1262 (inside the SiP)
Flash128 KB (~88% used)
RAM16 KB (~52% static)
Deep Sleep~3.5 µA

Default Radio Parameters (EU868)

Frequency869.618 MHz
Bandwidth62.5 kHz
Spreading FactorSF8
Coding Rate4/8
TX Power14 dBm (max)
Sync Word0x12
Serial Connection
Connect via USB and open a terminal at 115200 baud. Type help for the command list.

2. First Boot and Basic Setup

After flashing, the node automatically generates an Ed25519 identity. Then apply the minimal configuration:

set name MyRepeater
set lat 45.464161
set lon 9.191383
password MyAdminPassword
set guest.password MyGuestPassword
save
Important
Always run save after changing settings to store them permanently in EEPROM.

7. Passwords and Security

CommandDescription
passwordShow admin and guest passwords
password <pwd>Set admin password
set guest.password <pwd>Set guest password
get guest.passwordShow guest password
setperm <pubkey> <perm>Set per-node ACL permission (0-255, serial only)
Security
Always set the passwords before deployment. Remote sessions expire after 1 hour of inactivity. The rate limiter protects against brute-force attacks (5 login attempts/min).

8. Store-and-Forward Mailbox

The repeater stores messages for offline nodes and delivers them when the node comes back online (sends an ADVERT).

CommandDescription
mailboxStatus: used/total slots, EEPROM (E) and RAM (R) count
mailbox clearClear all slots (admin only)
Capacity
2 persistent EEPROM slots + 4 volatile RAM slots = 6 messages max, 24 hour TTL. No configuration needed.

10. Quiet Hours and Circuit Breaker

Quiet Hours

Reduces the forwarding rate during the configured hours. Requires TimeSync.

CommandDescription
quietShow quiet hours status
quiet <start> <end>Set quiet hours (0-23, e.g. quiet 22 6)
quiet offDisable quiet hours

Circuit Breaker

Blocks DIRECT forwarding to neighbours with a degraded link (SNR < -10 dB). After 5 minutes it goes half-open. A good SNR closes the breaker. FLOOD traffic is never blocked.

CommandDescription
cbShow the number of open circuit breakers

11. Rate Limiting

CommandDescription
ratelimitShow status and blocked counters
ratelimit on|offEnable/disable rate limiting
ratelimit resetReset counters

Default limits: Login 5/min, Request 30/min, Forward 100/min.

16. Configuration Profiles

Three preset profiles for common use cases.

MAXIMUM RANGE

Profile: Maximum Power and Coverage

For fixed installations with continuous power (solar, mains). Prioritises maximum coverage and network responsiveness.

Configuration commands

mode 0
sleep off
rxboost on
set tx 14
set tx auto off
set repeat on
set flood.max 15
set advert.interval 5
set af 0
set txdelay 50
set rxdelay 50
ratelimit on
alert on
save

Parameter notes

mode 0Performance: no power saving
sleep offDeep sleep disabled: always listening
rxboost onBoosted RX gain: better sensitivity
set tx 14Maximum TX power (14 dBm)
set tx auto offFixed power, no adaptive reduction
set flood.max 15Maximum hops for flood packets
set advert.interval 5ADVERT every 5 minutes (fast discovery)
set af 0Duty cycle disabled (unlimited TX)
set txdelay 50Shorter delay: faster responses
POWER SAVING

Profile: Minimum Battery Consumption

For battery-powered nodes in remote areas. Maximises battery life with the essential features.

Configuration commands

mode 2
sleep on
rxboost off
set tx auto on
set repeat on
set flood.max 3
set advert.interval 30
set af 20
set txdelay 200
set rxdelay 200
set flood.advert.interval 12
quiet 22 6
alert off
save

Parameter notes

mode 2Power Save: maximum saving
sleep onDeep sleep on: ~3.5 µA between RX windows
rxboost offStandard RX gain: lower consumption
set tx auto onAdaptive TX: lowers power when not needed
set flood.max 3Few hops: less network traffic
set advert.interval 30ADVERT every 30 min: fewer transmissions
set af 20Duty cycle 2x: longer wait between transmissions
set txdelay 200Longer delay: fewer collisions, more sleep
quiet 22 6Reduced forwarding from 22:00 to 06:00
BALANCED

Profile: Balanced Use

A compromise between coverage and battery life. Suitable for most installations.

Configuration commands

mode 1
sleep on
rxboost on
set tx auto on
set repeat on
set flood.max 7
set advert.interval 10
set af 10
set txdelay 100
set rxdelay 100
ratelimit on
alert on
save

Parameter notes

mode 1Balanced: good performance/consumption trade-off
sleep onDeep sleep on to save power between RX windows
rxboost onBoosted RX gain for better reception
set tx auto onAdaptive TX: power varies with link quality
set flood.max 7Good multi-hop range without excess traffic
set advert.interval 10ADVERT every 10 min: good compromise
set af 10Duty cycle 1.0x: standard
set txdelay 100Standard delay (default)
